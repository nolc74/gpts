# 영원의 구슬

모바일 세로 화면을 우선으로 하는 픽셀 아트 로그라이크 RPG 프로젝트.

## 핵심 콘셉트
- 위험한 던전에서 동료들에게 버려진 생존자가 던전 최심부에서 **영원의 구슬**을 얻으며 이야기가 시작된다.
- 영원의 구슬은 주인공이 영원히 살 수 있게 하는 핵심 스토리 아이템이다. 게임플레이용 부활 토큰이 아니다.
- 《모험가 이야기》와 유사한 텍스트·선택지 중심의 탐험과 랜덤 인카운터를 중심으로 한다.
- 매월 10일 여정을 떠나며, 마을에서는 장비 정비, 상점, 퀘스트, 훈련 등을 진행한다.
- 전체 스토리는 100장 구성을 목표로 한다.

## 기본 캐릭터 디자인 — 1차 시안
- 스타일: 선명한 픽셀 아트, 작은 화면에서도 읽히는 실루엣
- 분위기: 다크 판타지 생존자
- 색상: 검정, 짙은 보라, 보라색 발광 포인트
- 머리: 검은색에 가까운 짙은 보라색
- 눈: 보라색
- 복장: 후드 망토와 가죽 장비
- 장식: 별 모양 브로치
- 필요한 기본 모션: 대기, 걷기, 달리기, 공격, 점프, 피격
- 필요한 기본 표정: 기본, 눈 감음, 놀람, 분노, 의문, 부상, 수면

### 미확정 항목
- 주인공 이름과 외형 세부 설정
- 스프라이트 기준 크기, 프레임 수, 방향 수
- 최종 팔레트 및 애니메이션 속도

## 무기 및 직업 시스템 — 사용자 확정
- 주인공은 특정 기본 무기에 고정되지 않는다. 게임 내에서 어떤 종류의 무기든 획득해 사용할 수 있는 방향으로 설계한다.
- 직업은 무기 종류와 별개다. 무기를 얻었다고 자동으로 해당 무기 직업이 되는 것은 아니다.
- 마을에서 특정 조건을 달성하면 직업을 획득할 수 있다.
- 일반 직업 예시: 요리사, 벌목꾼, 검사, 마법사.
- 랜덤 인카운터 또는 메인 스토리에서 특정 조건을 만족하면 히든 직업을 획득할 수 있다.
- 히든 직업은 발견 조건을 만족해야 하며, 일반 직업과는 별도의 획득 경로를 가진다.
- 구체적인 직업 조건, 직업별 능력·성장·전투 효과, 동시 보유 가능 여부는 아직 미확정이다.

## 개발 원칙
- 확정된 설정과 제안 단계의 설정을 구분한다.
- 사용자 확인 없이 핵심 세계관이나 게임 규칙을 임의로 확정하지 않는다.
- 캐릭터 원화 시안과 실제 게임에서 사용할 스프라이트 시트를 구분한다.
