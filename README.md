# 영원의 구슬

모바일 세로 화면을 우선으로 하는 픽셀 아트 로그라이크 RPG 프로젝트.

## 핵심 콘셉트
- 위험한 던전에서 동료들에게 버려진 생존자가 던전 최심부에서 **영원의 구슬**을 얻으며 이야기가 시작된다.
- 영원의 구슬은 주인공이 영원히 살 수 있게 하는 핵심 스토리 아이템이다. 게임플레이용 부활 토큰이 아니다.
- 《모험가 이야기》와 유사한 텍스트·선택지 중심의 탐험과 랜덤 인카운터를 중심으로 한다.
- 매월 10일 여정을 떠나며, 마을에서는 장비 정비, 상점, 퀘스트, 훈련 등을 진행한다.
- 전체 스토리는 100장 구성을 목표로 한다.

## 기본 캐릭터 디자인 — 1차 시안
- 스타일: 선명한 픽셀 아트, 작은 화면에서도 읽히는 실루엣
- 분위기: 다크 판타지 생존자
- 색상 시안: 검정, 짙은 보라, 보라색 발광 포인트
- 머리 시안: 검은색에 가까운 짙은 보라색
- 눈 시안: 보라색
- 복장 시안: 후드 망토와 가죽 장비
- 장식 시안: 별 모양 브로치
- 필요한 기본 모션: 대기, 걷기, 달리기, 공격, 점프, 피격
- 필요한 기본 표정: 기본, 눈 감음, 놀람, 분노, 의문, 부상, 수면

### 캐릭터 선택 및 장비 외형 — 사용자 확정
- 게임 시작 시 남성형 또는 여성형 캐릭터를 선택할 수 있다.
- 두 체형은 같은 픽셀 아트 기준 크기와 장비 레이어 규격을 공유한다.
- 캐릭터의 기본 외형 위에 장비 스프라이트를 부위별 레이어로 합성한다.
- 장비를 착용하거나 해제하면 해당 부위의 외형이 바뀌어야 한다.
- 무기, 투구/모자, 몸통 방어구/의복, 장갑/팔 보호구, 다리 방어구, 신발, 망토/등 장식, 보조 장비 등을 독립적으로 표현할 수 있도록 설계한다.
- 장비가 없는 부위는 기본 캐릭터 외형이 보인다.
- 남성형/여성형의 세부 외모, 체형 차이, 스프라이트 픽셀 크기, 프레임 수, 방향 수, 최종 팔레트는 아직 미확정이다.
- 위의 검정·보라색 외형은 초기 시안이며 최종 디자인으로 확정된 것은 아니다.

## 무기 및 직업 시스템 — 사용자 확정
- 주인공은 특정 기본 무기에 고정되지 않는다. 게임 내에서 어떤 종류의 무기든 획득해 사용할 수 있는 방향으로 설계한다.
- 직업은 무기 종류와 별개다. 무기를 얻었다고 자동으로 해당 무기 직업이 되는 것은 아니다.
- 마을에서 특정 조건을 달성하면 직업을 획득할 수 있다.
- 일반 직업 예시: 요리사, 벌목꾼, 검사, 마법사.
- 랜덤 인카운터 또는 메인 스토리에서 특정 조건을 만족하면 히든 직업을 획득할 수 있다.
- 히든 직업은 발견 조건을 만족해야 하며, 일반 직업과는 별도의 획득 경로를 가진다.
- 획득한 직업은 플레이어가 원할 때 포기할 수 있다.
- 직업을 포기하면 해당 직업의 **직업 스킬은 유지**되지만, 해당 직업에 귀속된 **직업 특성은 사라진다**.
- 따라서 직업을 포기한 뒤에도 과거 직업에서 배운 스킬을 계속 사용할 수 있지만, 그 직업의 고유 특성 효과는 더 이상 적용되지 않는다.
- 구체적인 직업 조건, 직업별 능력·성장·전투 효과는 아직 미확정이다.

## 레벨·경험치·스킬 장착 시스템 — 사용자 확정
### 레벨 상한 및 스킬 장착 칸
- 최대 레벨은 11이다.
- 1레벨: 스킬 3개 장착 가능.
- 2레벨: 스킬 4개 장착 가능.
- 3~11레벨의 스킬 장착 칸 수는 아직 미정이며, 임의로 추정하지 않는다.

### 경험치 획득
- 경험치는 다음 도감의 항목을 처음 해금할 때 획득한다.
  - 몬스터 도감
  - 아이템 도감
  - 스킬 도감
  - 특성 도감
- 각 도감 항목은 최초 해금 시에만 경험치를 지급한다.
- 이미 해금한 항목을 다시 발견하거나 획득해도 같은 항목에서 경험치를 중복 지급하지 않는다.
- 모든 도감 항목을 해금했을 때 얻는 경험치 총량은 11레벨 달성에 필요한 경험치보다 적어야 한다.
- 따라서 도감을 전부 해금하더라도 경험치만으로 최대 레벨 11에 도달할 수는 없다.
- 도감 항목별 경험치량과 레벨업 필요 경험치 공식은 미정이다.

### 레벨업 세부 스탯 보상
- 기본 스탯은 해당 기본 스탯에 속한 20개 세부 스탯의 산술평균이다. 따라서 레벨업으로 기본 스탯을 올릴 때는 세부 스탯이 직접 증가해야 한다.
- 레벨업 시 새 레벨이 아니라 **레벨업 직전 레벨 수치만큼** 각 기본 스탯에 속한 세부 스탯 전체가 각각 증가한다.
- 예시: 1레벨에서 2레벨이 되면 6개 기본 스탯 각각의 세부 스탯 20개가 모두 +1 된다.
- 예시: 2레벨에서 3레벨이 되면 6개 기본 스탯 각각의 세부 스탯 20개가 모두 +2 된다.
- 세부 스탯의 평균이 변하므로 기본 스탯도 자동으로 증가한다.

## 기본 스탯 시스템
- 기본 스탯은 힘, 지능, 민첩, 체력, 마력, 정신의 6종이다.
- 각 기본 스탯은 20개의 세부 스탯으로 구성되며, 총 120개의 세부 스탯을 사용한다.
- 기본 스탯 = 해당 20개 세부 스탯 합계 ÷ 20.
- 초기 기본 스탯은 모두 10이며, 따라서 각 세부 스탯도 최초 10으로 시작한다.
- 세부 스탯은 독립적으로 성장할 수 있다. 특정 세부 스탯이 성장하면 해당 기본 스탯의 평균도 함께 변한다.
- 세부 스탯은 훈련, 전투, 장비, 퀘스트, 이벤트 등에 의해 성장할 수 있다.

## 랜덤 인카운터와 세부 스탯 판정
- 세부 스탯은 랜덤 인카운터의 성공·실패, 선택지 해금, 결과 및 불이익에 직접 영향을 준다.
- 특정 행동에는 관련 세부 스탯 요구치가 있을 수 있다.
- 요구치를 충족하지 못하면 행동 실패, 자원 소모, 부상, 피로, 중독, 공포, 혼란, 보상 감소 등의 불이익이 발생할 수 있다.
- 예시: 무거운 문 열기(근력), 좁은 통로 통과(유연성), 함정 발견(분석력), 독버섯 판별(생물학지식), 공포 저주 저항(공포저항), 마법진 해제(마력제어).
- 낮은 수치가 언제나 자동 실패를 뜻하는 것은 아니며, 상황과 판정 설계에 따라 결과가 달라질 수 있다.
- 120개 세부 스탯 모두를 인카운터, 선택지, 조건, 결과 등에 활용하는 것을 목표로 한다.

## 개발 원칙
- 확정된 설정과 제안 단계의 설정을 구분한다.
- 사용자 확인 없이 핵심 세계관이나 게임 규칙을 임의로 확정하지 않는다.
- 캐릭터 원화 시안과 실제 게임에서 사용할 스프라이트 시트를 구분한다.


## 시작 화면 프로토타입
- 실제 시작 화면 프로토타입은 저장소 루트의 `index.html`이다.
- 플레이어가 남성형 또는 여성형을 직접 선택한다.
- 플레이어가 이름을 직접 입력한다. 기본 이름은 지정하지 않는다.
- 선택한 성별에 따라 픽셀 캐릭터 미리보기가 바뀐다.
- 이름을 입력하고 시작 버튼을 누르면 캐릭터 정보가 현재 브라우저 세션에 저장된다.
- 현재는 캐릭터 생성 화면 프로토타입이며, 특성 무작위 생성과 프롤로그 게임 진행은 아직 연결하지 않았다.
